# Backend and RAG Interview Guide

## Interview Focus
For backend Python candidates, interviewers should look for clean functions, meaningful exception handling, testable modules, secure configuration, database reasoning, and API integration experience.

For RAG candidates, interviewers should ask how the candidate chunks documents, uses metadata, handles weak retrieval results, cites sources, avoids exposing private data, and evaluates retrieval quality with regression examples.

## Evidence Rules
Interview notes should separate verified resume evidence from interviewer impressions. Candidate-facing summaries should not include raw phone numbers, email addresses, or unsupported claims. If the retrieved material is unrelated or too weak, the assistant should clearly state that there is insufficient evidence.
